Durante o desenvolvimento de aplicações Spring Boot, especialmente serviços RESTful, é comum utilizar ferramentas para **testar, documentar e consumir APIs**. As principais são:

### Postman

O **Postman** é uma das ferramentas mais populares para testes de APIs REST.

Principais recursos:

- Criação e execução de requisições HTTP
    
- Organização por coleções e ambientes
    
- Suporte a autenticação (Basic, Bearer, OAuth, etc.)
    
- Automação de testes simples
    

Download:

- https://www.postman.com/downloads/
    

### Insomnia

O **Insomnia** é uma alternativa leve e eficiente para testes de APIs REST e GraphQL.

Principais recursos:

- Interface simples e intuitiva
    
- Suporte a REST, GraphQL e gRPC
    
- Gerenciamento de variáveis de ambiente
    

Download:

- https://insomnia.rest/download
    

### Bruno

O **Bruno** é uma ferramenta moderna, open source, voltada a testes de APIs com foco em versionamento.

Principais recursos:

- Armazena coleções em arquivos locais (Git-friendly)
    
- Interface simples
    
- Ideal para times que versionam testes junto ao código-fonte
    

Download:

- https://www.usebruno.com/downloads
    

### SoapUI

O **SoapUI** é amplamente utilizado para testes de serviços **SOAP**, mas também oferece suporte a REST.

Principais recursos:

- Testes funcionais e de carga
    
- Forte suporte a Web Services SOAP
    
- Utilizado com frequência em ambientes corporativos
    

Download:

- https://www.soapui.org/
